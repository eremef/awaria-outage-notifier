style: Upgrade utility icons to SVGs and improve High-Contrast accessibility

Maintainer Notes:
- Accessibility: Replaced default checkboxes with pure CSS custom checkboxes (`appearance: none`) to bypass browser rendering bugs in High-Contrast mode. Added both `:checked` (checkmark) and `:indeterminate` (horizontal dash) states.
- High-Contrast: Forced all provider accent variables and utility SVGs to map to `var(--primary-color)` ensuring strict WCAG 2.2 AAA contrast compliance against dark backgrounds.
- UI Consistency: Swapped OS-dependent utility emojis for standard inline SVGs (droplet, flame, thermometer, zap) with explicit color mapping and fixed flexbox squishing bugs.
- Clean-up: Removed redundant `<span class="outage-type">` from outage cards and purged unused `lbl_section_*` translation keys.

Summary of Changes:
- `public/script.js`: Replaced `getSourceEmoji` with `getSourceIcon` returning SVGs. Removed `outage-type` span from `renderCards`. Added `utility-icon` span wrapper.
- `public/style.css`: Added CSS rules for `.utility-svg`, color mappings (`.water-icon`, etc.), and flexbox alignment. Implemented custom High-Contrast checkboxes and color overrides.
- `public/i18n.js`: Removed unused `lbl_section_*` string keys.

User-facing:
- Settings checkboxes now render correctly in High-Contrast mode (including the partial/indeterminate state).
- Alert group headers now use modern, crisp SVG icons (colored correctly for water, gas, heat, and power) instead of emojis.
- Removed redundant provider name labels from individual outage cards for a cleaner UI.
