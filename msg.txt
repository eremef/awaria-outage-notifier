fix: Remove Rust symbol stripping for Google Play Console compatibility

Maintainer Notes:
- Build: Removed `strip = true` from the Cargo release profile. Cargo was aggressively stripping symbols from `libapp_lib.so` before the Google Play Console ZIP was generated by GitHub Actions. This caused the Play Console to reject the native symbols upload since it requires unstripped libraries. 
- Build: The final Android APK/AAB size remains unaffected because the Android Gradle Plugin automatically strips native libraries during the final packaging phase.
- Release: Bumped version to `1.0.62`.

Summary of Changes:
- `src-tauri/Cargo.toml`: Removed `strip = true` and bumped version to `1.0.62`.
- `package.json`: Bumped version to `1.0.62`.
- `awaria_outage_monitor/config.yaml`: Bumped version to `1.0.62`.

User-facing:
- None directly. This ensures native crash symbols are successfully uploaded to Google Play for better crash reporting.
