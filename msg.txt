refactor: Consolidate identical Android widget info XML files

Maintainer Notes:
- Architecture: Consolidated 22 identical 1x1 widget provider configurations into a single `widget_single_info.xml` file. Android allows multiple `<receiver>` tags to reference the same `@xml/appwidget-provider` resource without issue, significantly reducing boilerplate and keeping the configurations DRY.
- Cleanup: The 3x1 and 4x1 composite widgets (`AllWidgetProvider` and `TriWidgetProvider`) retain their separate config files because they define different dimensions and initial layouts.

Summary of Changes:
- `src-tauri/gen/android/app/src/main/res/xml/`: Deleted 21 duplicate `widget_*_info.xml` files and renamed `widget_tauron_info.xml` to `widget_single_info.xml`.
- `src-tauri/gen/android/app/src/main/AndroidManifest.xml`: Updated the `<meta-data android:resource="..."/>` values for all single-provider receivers to point to `@xml/widget_single_info`.

User-facing:
- No visual or functional changes for the end-user. Just cleaning up the project's internal files.
